## 📖 About

Whenever I build something useful in data science, I upload the code here so that other learners can **use it, study it, and improve it**. Each notebook solves one specific problem step by step.

## 📂 Contents

| # | Notebook | Topic | What it covers |
|---|----------|-------|----------------|
| 1 | [Correlation](./Corelation.ipynb) | Statistics | Finding and visualizing the relationship between variables |
| 2 | [Outlier](./outlier.ipynb) | Data Cleaning | Detecting and handling outliers in data |

> 🔄 New notebooks are added regularly.

## 🎯 Topics Covered

- 📊 **Statistics**: correlation and data relationships
- 🧹 **Data Cleaning**: outlier detection and handling
- 📈 **Visualization**: charts to understand data
- 🤖 **Machine Learning**: models and experiments in Python

## 🛠 Tech Stack

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

## 🚀 How to Use

1. Clone the repository
```bash
   git clone https://github.com/ahsanullahghani000-png/Data-Science-Lab.git
```
2. Go into the folder
```bash
   cd Data-Science-Lab
```
3. Install the libraries
```bash
   pip install pandas numpy matplotlib seaborn jupyter
```
4. Open Jupyter and run any notebook
```bash
   jupyter notebook
```
